## Overview
SafeSphere.AI is a real-time AI moderation engine that analyses more than 10,000 text and image samples for toxicity and unsafe content.

## Accuracy and performance
It reaches over 95% detection accuracy using the Bytez.js and Sightengine APIs. Redis-based async processing cut latency by 35% to about 1.5 seconds.

## Data and logging
MongoDB stores over 50,000 moderation logs, user reports and audit history. Tech stack: HTML, CSS, JavaScript, Redis, MongoDB, Bytez.js and Sightengine.
