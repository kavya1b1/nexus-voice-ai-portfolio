## Overview
The n8n Workflow Generator is a Chrome extension that turns a plain-text prompt into a complete n8n automation workflow.

## How it works
It uses DeepSeek R1 through OpenRouter to generate native n8n JSON, which is copied to your clipboard, ready to import into n8n. A Gmail email-classification workflow is included as an example. Tech stack: JavaScript, Chrome Extension APIs, OpenRouter, DeepSeek R1 and n8n.
